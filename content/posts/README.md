# Via Ferrata
Via Ferrata in Switzerland and elsewhere, help organise recurring events in Ferrata Together meetup group.

These files are kind of templates so you can create standardised events in meet-up, WhatsApp

Links in each templates are for giving you more detailed informations and finding GPS files you can use in Swisstopo or Komodo

# How to use
Open the file where you want to organise your event and change
- Recommended train
- Meeting point time
- Time of leaving
- WhatsApp room
- ...

Protect all links from post use https://www.shieldmylinks.com or any other services
