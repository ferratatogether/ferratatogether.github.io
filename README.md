## Templates
We can influence how a new page is created in Hugo by using archetypes. Archetypes are content templates stored in our project's archetypes/ directory that pre-populate new files with front matter and default body text. see the archetype archetypes/default.md

use with
```hugo new content/posts/switzerland/XXXXXX/index.md```
